## Bounded product contract

- A public Activity is represented in the city Telegram forum General topic as one photo message.
- The photo/media is immutable after first publication.
- Editable Activity information lives in the photo caption.
- Shared buttons are Details + Participate.
- No physical pin is required for the city-card feed.
- New publication temporarily reopens the General topic, publishes, then closes it again.
- Existing tracked publication edits caption/reply markup only. If Telegram rejects edit because the topic is closed, the code performs bounded reopen -> edit -> close.
- Shared message state remains common to all users. Per-user participation feedback remains an ephemeral callback response.
